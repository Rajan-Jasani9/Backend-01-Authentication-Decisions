# Architecture prompt

Inspect the application and the completed decision checklist. Identify missing requirements; do not silently select security-critical defaults. Compare supported identity providers or maintained libraries with application-managed alternatives. Produce a decision record, data model, trust boundaries and concrete login, protected-request, logout, recovery, identity-change and incident flows. Distinguish authentication from resource authorization. Define CSRF, account linking, account states, hashing, session lifetimes and revocation guarantees. Specify outage behavior and deployment compatibility. Identify which requirements differ from reference-architecture.md. Explain alternatives and trade-offs. Request design approval before implementation.
