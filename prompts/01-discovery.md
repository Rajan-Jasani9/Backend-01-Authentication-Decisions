# Discovery prompt

Before implementing authentication, inspect the existing application architecture, dependencies, clients and deployment. Ask about identity groups, organizations, login methods, account states, authorization, session lifecycle, revocation latency, browser architecture, recovery, MFA, abuse, secret storage, observability and failure behavior. Use decision-checklist.md to track answers. Do not silently choose security-critical defaults. Separate known requirements from open questions. Produce a requirements document with constraints, alternatives to evaluate and explicit acceptance criteria for the architecture phase.
